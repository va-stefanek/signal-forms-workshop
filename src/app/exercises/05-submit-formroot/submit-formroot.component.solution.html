05 - Submit & FormRoot

Two ways to handle submission: submit() vs [formRoot]

🎯 Learning Goals:
  • Use submit() with action + onInvalid
  • Auto-focus invalid fields with errorSummary() + focusBoundControl()
  • Show submitting() loading state
  • Declare submission inside form() 3rd argument
  • Use [formRoot] — no onSubmit() method needed

Part A — submit() imperative

Submission logic lives in an onSubmit() method.

💡 Part A — submit() pattern (click to expand) 
async onSubmitA() {
  this.successA.set(null);

  await submit(this.formA, {
    action: async (field) => {
      await new Promise(r => setTimeout(r, 1500));
      this.successA.set('Sent!');
      this.modelA.set({ ...INITIAL });  // reset data
      field().reset();                  // reset touched/dirty
      return undefined;                 // success
    },
    onInvalid: (field) => {
      field().errorSummary()[0]?.fieldTree().focusBoundControl();
    }
  });
}
💡 Part B — [formRoot] pattern (click to expand) 
// Submission logic goes into the 3rd argument of form():
protected readonly formB = form(this.modelB, (f) => {
  required(f.name);
  // ...validators
}, {
  submission: {
    action: async (field) => {
      await new Promise(r => setTimeout(r, 1500));
      this.successB.set('Sent!');
      this.modelB.set({ ...INITIAL });
      field().reset();
      return undefined;
    },
    onInvalid: (field) => {
      field().errorSummary()[0]?.fieldTree().focusBoundControl();
    }
  }
});
